דף עבודה: מבוא ליצירת מחלקות ב-Java

הסבר על הפקודה: בסביבת Java, מחלקה (class) היא ה"תבנית" או "תכנית העבודה" שממנה אנו מייצרים עצמים (אובייקטים). היא מגדירה אילו תכונות (משתנים) יהיו לאובייקט ואילו פעולות (מתודות) הוא יוכל לבצע.

וריאציה: כאשר אנו יוצרים מחלקה שמטרתה לייצג ישות (כמו קוביה או תלמיד), לרוב לא נשים בתוכה את הפעולה public static void main. את ה-main נשמור במחלקה נפרדת שמפעילה את התוכנית (מחלקת הרצה).

שלב 1: העתקת קוד וניתוח (צעד אחר צעד)

העתיקו את קוד המקור הבא לסביבת הפיתוח שלכם (Eclipse / IntelliJ / BlueJ).

שימו לב: יש ליצור קובץ חדש בשם התואם בדיוק לשם המחלקה.

דוגמה א': מחלקה לייצוג קוביית משחק

פתחו קובץ בשם Dice.java והעתיקו רק את התוכן שבתוך הקווים המקווקווים:

Java

public class Dice {

    // תכונות המחלקה (משתנים)

    public int sides;

    public String color;

    // פעולה (מתודה) שמציגה את פרטי הקובייה

    public void displayDetails() {

        System.out.println("קובייה בצבע " + color + " עם " + sides + " פאות.");

    }

}

דוגמה ב': מחלקה לייצוג מלבן

פתחו קובץ בשם Rectangle.java והעתיקו רק את התוכן שבתוך הקווים המקווקווים:

Java

public class Rectangle {

    // תכונות המלבן

    public double width;

    public double height;

    // פעולה לחישוב והדפסת השטח

    public void printArea() {

        double area = width * height;

        System.out.println("שטח המלבן הוא: " + area);

    }

}

שאלה למחשבה: בהסתמך על שתי הדוגמאות שהעתקתם, מה תפקידה של המילה class בקוד, ומה ההבדל בין המשתנים שמוגדרים בתוכה לבין משתנים רגילים שראינו עד היום בתוך פעולת ה-main?

שלב 4: תרגול מעשי עצמאי (מדורג מהקל אל הקשה)

תרגיל 1 (קל מאוד)

צרו מחלקה בשם Student (תלמיד). למחלקה צריכות להיות שתי תכונות בלבד: שם התלמיד (מחרוזת) וממוצע הציונים שלו (מספר ממשי).

תרגיל 2 (קל)

צרו מחלקה בשם Product (מוצר בחנות) עם התכונות: שם המוצר ומחירו בשקלים. הוסיפו למחלקה פעולה בשם printPrice שמדפיסה את מחיר המוצר בתוספת הסימן "₪".

תרגיל 3 (קל)

צרו מחלקה בשם Circle (עיגול) עם תכונה אחת: רדיוס (radius) מסוג מספר ממשי. הוסיפו פעולה בשם calculateCircumference שמחשבת ומדפיסה את היקף המעגל ($2 \cdot \pi \cdot radius$).

רמז: ניתן להשתמש ב-3.14 עבור פאי.

תרגיל 4 (בינוני)

צרו מחלקה בשם BankAccount (חשבון בנק) עם התכונות: שם בעל החשבון ויתרת החשבון (balance). הוסיפו פעולה בשם deposit שמקבלת כפרמטר סכום כסף (מספר שלם) ומוסיפה אותו ליתרה הקיימת.

תרגיל 5 (בינוני)

צרו מחלקה בשם LightBulb (נורה) עם התכונות: מותג הנורה והאם היא דולקת כרגע (isOn מסוג בוליאני). הוסיפו פעולה בשם toggle שהופכת את מצב הנורה (אם היא דלקה - היא תכבה, ואם הייתה כבויה - תידלק).

רמז: השתמשו באופרטור השלילה !.

תרגיל 6 (בינוני)

צרו מחלקה בשם Time המייצגת זמן ביום באמצעות שתי תכונות: שעות (hours) ודקות (minutes). הוסיפו פעולה בשם isMinutesValid המחזירה true אם ערך הדקות הוא חוקי (בין 0 ל-59 כולל), ואחרת מחזירה false.

תרגיל 7 (מתקדם)

צרו מחלקה בשם TemperatureConverter. אין לה תכונות. יש לה פעולה אחת בשם toFahrenheit שמקבלת מעלות בצלזיוס (מספר ממשי) כמחרוזת/פרמטר, ומחזירה את הערך המומר בפרנהייט לפי הנוסחה: $F = (C \cdot 9/5) + 32$.

תרגיל 8 (מתקדם)

צרו מחלקה בשם Smartphone. תכונות: מותג, נפח סוללה (0-100), ונפח אחסון פנוי בגיגה-בייט. הוסיפו פעולה בשם downloadApp שמקבלת כפרמטר את גודל האפליקציה בגיגה-בייט. הפעולה תבדוק: אם יש מספיק מקום, היא תחסיר את הגודל מהאחסון הפנוי ותדפיס "הורדה הצליחה". אם אין מספיק מקום, תדפיס "אין מקום באחסון".

תרגיל 9 (קשה)

צרו מחלקה בשם Flight (טיסה). תכונות: מספר טיסה, יעד, ומספר מקומות מקסימלי במטוס, ומספר הנוסעים שרשומים כרגע (bookedSeats). הוסיפו פעולה בשם addPassenger. הפעולה תצרף נוסע לטיסה (תגדיל את bookedSeats ב-1) רק אם המטוס לא מלא. אם המטוס מלא, תודפס הודעת אזהרה מתאימה.

תרגיל 10 (אתגר)

צרו מחלקה בשם Character המייצגת דמות במשחק מחשב. תכונות: שם הדמות, נקודות חיים (healthPoints - מתחיל ב-100) ומצב "האם חיה" (isAlive - מתחיל כ-true). הוסיפו פעולה בשם takeDamage המקבלת כפרמטר כמות נזק (מספר שלם). הפעולה תפחית את נקודות החיים של הדמות בהתאם לנזק. אם נקודות החיים יורדות ל-0 או פחות, נקודות החיים יתאפסו והמצב isAlive ישתנה ל-false.

רמז: ודאו שנקודות החיים לא הופכות למספר שלילי בקוד, והשתמשו בתנאי if לבדיקת מצב הדמות.

בהצלחה רבה לכל התלמידים! תרגול של בניית מחלקות נכונה הוא הבסיס לכל עולם התכנות מונחה העצמים (OOP).
