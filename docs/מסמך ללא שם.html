דף עבודה בג׳אווה — פונקציות / מתודות

ב־Java נהוג לקרוא לפונקציות בשם מתודות. מתודה היא קטע קוד עם שם, שאפשר לקרוא לו כמה פעמים במקום לכתוב את אותו קוד שוב ושוב.
הגדרת מתודה כוללת בדרך כלל: הרשאת גישה, static כשקוראים מתוך main, סוג ערך מוחזר, שם המתודה, וסוגריים לפרמטרים. מתודה מסוג void אינה מחזירה ערך, ומתודה שאינה void חייבת להחזיר ערך מתאים בעזרת return. (docs.oracle.com)

חלק א׳ — העתקת קוד והרצה

דוגמה 1 — מתודה שלא מחזירה ערך: void

המתודה printTitle מבצעת פעולה: היא מדפיסה למסך.
היא לא מחזירה ערך, ולכן סוג ההחזרה שלה הוא void.

אין להעתיק את הקווים המקווקווים.

-------------------------------- התחלת קוד להעתקה --------------------------------

public class FunctionPrintDemo {

    public static void printTitle() {

        System.out.println("Learning Java Functions");

    }

    public static void printStars() {

        System.out.println("**********");

    }

    public static void main(String[] args) {

        printStars();

        printTitle();

        printStars();

    }

}

שאלות:

  1. מה עושה המתודה printTitle?
  2. כמה פעמים מופיעה קריאה למתודה בתוך main?
  3. למה לדעתכם השתמשנו במילה void?

דוגמה 2 — מתודה שמחזירה ערך עם return

המתודה sum מקבלת שני מספרים ומחזירה את הסכום שלהם.
כיוון שהיא מחזירה מספר שלם, סוג ההחזרה שלה הוא int.

-------------------------------- התחלת קוד להעתקה --------------------------------

public class FunctionReturnDemo {

    public static int sum(int a, int b) {

        return a + b;

    }

    public static int multiplyByTwo(int num) {

        return num * 2;

    }

    public static void main(String[] args) {

        int x = sum(4, 7);

        int y = multiplyByTwo(x);

        System.out.println(x);

    }

}

רמזים לתרגילים הקשים

  • בתרגיל פלינדרום: אפשר להפוך את המספר בעזרת % 10 ו־/ 10.
  • בתרגיל מערך זוגיים בלבד: קודם ספרו כמה זוגיים יש, ואז צרו מערך בגודל מתאים.
  • בתרגיל השוואת מערכים: קודם בדקו אורך, אחר כך עברו איבר־איבר.
  • בתרגיל מערך ממוין: מספיק למצוא פעם אחת שבה arr[i] > arr[i + 1] כדי להחזיר false.
  • בתרגיל ניהול ציונים: חלקו את הבעיה למתודות קטנות, למשל average, maxGrade, countFailed.
