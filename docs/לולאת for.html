דף עבודה 2: לולאת for – חוזרים על פעולות בקלות

מה נלמד? לולאת for משמשת להרצת בלוק של קוד מספר פעמים ידוע מראש.

מבנה הלולאה: היא מורכבת משלושה חלקים: אתחול המונה, תנאי עצירה (עד מתי להמשיך), וקידום המונה (בכמה להגדיל בכל פעם).

שלב 1: העתקת קוד (למידה דרך הידיים)

העתיקו את תוכן הקוד הבא. שימו לב למשתנה $i$ – הוא ה"מונה" שלנו שסופר את הסיבובים.

דוגמה א': הדפסת מספרים מ-1 עד 5

Java

public class CountToFive {

    public static void main(String[] args) {

// ------------------------------------------------------------

        for (int i = 1; i <= 5; i++) {

            System.out.println("Number: " + i);

        }

// ------------------------------------------------------------

    }

}

דוגמה ב': הדפסת משפט מספר פעמים

Java

public class RepeatMessage {

    public static void main(String[] args) {

// ------------------------------------------------------------

        for (int i = 0; i < 3; i++) {

            System.out.println("I love Java!");

        }

// ------------------------------------------------------------

    }

}

שלב 3: השלמת קוד (מלאו את החסר)

השלימו את החלקים החסרים כדי שהלולאה תבצע את המשימה:

1. הדפסה 10 פעמים:

for (int i = 0; i < ____ ; i++) {

System.out.println("Hello");

}

2. ספירה בקפיצות של 2 (2, 4, 6...):

for (int i = 2; i <= 10; i = i + ____ ) {

System.out.println(i);

}

3. השלמת סוגריים ופקודה:

System.out.println("Looping...");

שלב 4: משימות תכנות (מהקל אל הכבד)

  1. ספירה פשוטה: הדפיסו את המספרים מ-1 עד 10.
  2. שם חוזר: הדפיסו את השם שלכם 7 פעמים (כל פעם בשורה חדשה).
  3. ספירה לאחור: הדפיסו את המספרים מ-10 עד 1 (השתמשו ב-i--).
  4. זוגיים בלבד: הדפיסו את כל המספרים הזוגיים בין 2 ל-20.
  • רמז: התחילו ב-2 וקדמו את המונה ב-2 בכל פעם (i += 2).
  1. ריבוע מספרים: הדפיסו 4 שורות, שבכל שורה מופיע המספר "5".
  2. טור כוכביות: הדפיסו טור של 5 כוכביות אחת מתחת לשנייה.
  3. שורת כוכביות: הדפיסו שורה של 10 כוכביות בעזרת print.
  4. לוח הכפל (חלקי): הדפיסו את כפולות המספר 5 (מ-5 עד 50).
  5. מדרגות מספרים: השתמשו בלולאה כדי להדפיס: 10, 20, 30, 40, 50.
  6. אתגר - סכום (ללא משתנה חיצוני): הדפיסו את המשפט "הסיבוב הנוכחי הוא: " בצירוף מספר הסיבוב, אך התחילו לספור מהמספר 100 ועד 105.

טיפ מהמדריך: אם הלולאה שלכם לא עוצרת ("לולאה אינסופית"), בדקו אם תנאי העצירה שלכם הגיוני! למשל, אם אתם עולים ב-i++ אבל בודקים אם i > 0, זה לעולם לא ייגמר.
