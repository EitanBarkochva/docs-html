תקציר ג'מיני

1. הדפסה (Output)

הדרך של התוכנית להציג מידע על המסך.

  • System.out.println(...) – מדפיס ויורד שורה.
  • System.out.print(...) – מדפיס ונשאר באותה שורה.

דוגמה בסיסית:

Java

System.out.print("Hello ");

System.out.println("World!"); // פלט: Hello World! בשורה אחת

דוגמה מורכבת ( שרשור משתנים וטקסט):

Java

int age = 17;

// שרשור מחרוזת עם משתנה וביצוע חישוב מתמטי בתוך ההדפסה באמצעות סוגריים

System.out.println("Next year, you will be: " + (age + 1) + " years old.");

2. משתנים (Variables)

"קופסאות" בזיכרון לשמירת נתונים. ב-Java חובה להצהיר על סוג המשתנה.

  • int – מספרים שלמים (למשל: 5, 0, -12).
  • double – מספרים עשרוניים (למשל: 5.75, -3.14).
  • char – תו בודד, מוקף בגרש יחיד (למשל: 'A', '?').
  • boolean – ערך לוגי: true או false.
  • String – מחרוזת טקסט (לא טיפוס פרימיטיבי, מתחיל באות גדולה), מוקפת במרכאות (למשל: "Jerusalem").

דוגמה בסיסית:

Java

int count = 10;

double price = 49.90;

char grade = 'A';

boolean isPassed = true;

String name = "Ethan";

דוגמה מורכבת (המרת טיפוסים ופעולות):

Java

int sum = 15;

int count = 4;

// חלוקת שלמים תיתן תוצאה שלמה (3). כדי לקבל דיוק עשרוני, נכפיל ב-1.0 או נבצע Casting

double average = (double) sum / count; // תוצאה: 3.75

3. קליטת מידע מהמשתמש (Input)

כדי לקלוט נתונים, משתמשים במחלקה Scanner. בתחילת הקובץ יש לייבא אותה: import java.util.Scanner;.

  • nextIn(), nextDouble(), next() (למילה בודדת), nextLine() (לשורה שלמה).

דוגמה בסיסית:

Java

Scanner in = new Scanner(System.in);

System.out.println("Enter your height: ");

double height = in.nextDouble();

דוגמה מורכבת (ניקוי הבאפר):

כשקולטים מספר ואחריו מחרוזת (String) עם nextLine(), ה-Enter של המספר עלול "להיבלע". פותרים זאת ע"י קריאת סרק:

Java

Scanner in = new Scanner(System.in);

System.out.println("Enter age: ");

int age = in.nextInt();

in.nextLine(); // פקודת סרק לניקוי ה-Enter מהבאפר

System.out.println("Enter full name: ");

String fullName = in.nextLine(); // כעת הקליטה תעבוד בצורה תקינה

4. תנאים (If - Else)

ביצוע פעולות רק אם תנאי מסוים מתקיים. באים לידי ביטוי גם הקשרים הלוגיים: && (וּגַם), || (אוֹ), ! (היפוך/שלילה).

דוגמה בסיסית:

Java

int score = 85;

if (score >= 56) {

    System.out.println("Passed!");

} else {

    System.out.println("Failed.");

}

דוגמה מורכבת (תנאים מקוננים ומורכבים):

Java

int age = 17;

boolean hasLicense = true;

if (age >= 17 && hasLicense) {

    System.out.println("You can drive alone!");

} else if (age >= 17 && !hasLicense) {

    System.out.println("You are old enough, but need to pass the test.");

} else {

    System.out.println("Too young to drive.");

}

5. לולאות (Loops: While & For)

חזרה על קטע קוד מספר פעמים.

  • for – כשנרצה לרוץ מספר פעמים ידוע מראש (למשל: על מערך, או 10 פעמים).
  • while – כשמספר הפעמים אינו ידוע מראש ותלוי בתנאי (למשל: עד שיוקלט מספר שלילי).

דוגמה בסיסית (for):

Java

// הדפסת המספרים מ-1 עד 5

for (int i = 1; i <= 5; i++) {

    System.out.print(i + " ");

}

דוגמה בסיסית (while):

Java

// לולאת זקיף - קליטה עד שמוקלט מספר שלילי

Scanner in = new Scanner(System.in);

System.out.println("Enter a number (negative to stop): ");

int num = in.nextInt();

while (num >= 0) {

    System.out.println("You entered: " + num);

    num = in.nextInt(); // קליטה מחדש בתוך הלולאה!

}

דוגמה מורכבת (לולאה עם צבירה וסינון):

Java

// קליטת 10 מספרים, חישוב סכום הזוגיים בלבד וספירת השליליים

Scanner in = new Scanner(System.in);

int sumEven = 0;

int countNeg = 0;

for (int i = 0; i < 10; i++) {

    System.out.println("Enter number: ");

    int num = in.nextInt();

   

    if (num % 2 == 0) {

        sumEven += num; // צבירת סכום

    }

    if (num < 0) {

        countNeg++; // ספירת כמות

    }

}

6. מערכים (Arrays) – דגש מוגבר

אוסף משתנים מאותו סוג תחת שם אחד. גודל המערך קבוע מרגע יצירתו.

  • האינדקס הראשון הוא תמיד 0.
  • האינדקס האחרון הוא תמיד arr.length - 1.

דוגמה בסיסית (הגדרה וגישה):

Java

int[] grades = new int[5]; // מערך בגודל 5, כרגע מאופס

grades[0] = 90; // השמת ערך באינדקס הראשון

grades[4] = 100; // השמת ערך באינדקס האחרון

דוגמה מורכבת (סריקת מערך, מציאת מקסימום וסינון - קלאסי לבגרות):

Java

int[] arr = {12, 45, 7, 23, 45, 9};

int max = arr[0]; // מניחים שהראשון הוא המקסימלי

int countMax = 0;

// שלב א': מציאת ערך המקסימום

for (int i = 1; i < arr.length; i++) {

    if (arr[i] > max) {

        max = arr[i];

    }

}

// שלב ב': ספירה כמה פעמים המקסימום מופיע במערך

for (int i = 0; i < arr.length; i++) {

    if (arr[i] == max) {

        countMax++;

    }

}

System.out.println("Max value is " + max + ", appears " + countMax + " times.");

7. פונקציות / פעולות (Methods) – דגש מוגבר

תת-תוכנית שמבצעת משימה מוגדרת. עוזרת לשמור על סדר ומניעת כפל קוד.

  • ערך מוחזר (return): אם הפונקציה מחזירה ערך, נכתוב את הטיפוס שלו (למשל int). אם היא רק מבצעת ולא מחזירה, נכתוב void.
  • פרמטרים: המשתנים שהפונקציה מקבלת מבחוץ לצורך החישוב.

דוגמה בסיסית (פעולת void לעומת פעולה מחזירה):

Java

// פעולה שמחזירה ערך - מקבלת שני מספרים ומחזירה את הגדול מביניהם

public static int getMax(int a, int b) {

    if (a > b) {

        return a;

    }

    return b;

}

// פעולת void - לא מחזירה כלום, רק מדפיסה

public static void printStars(int num) {

    for (int i = 0; i < num; i++) {

        System.out.print("*");

    }

    System.out.println();

}

דוגמה מורכבת (פונקציה המקבלת ומעבדת מערך):

בבגרות 3 יח' יש כמעט תמיד שאלה שדורשת לכתוב פעולה שמקבלת מערך.

Java

// פעולה שמקבלת מערך של מספרים שלמים ומחזירה true אם כל המספרים חיוביים

public static boolean isAllPositive(int[] numbers) {

    for (int i = 0; i < numbers.length; i++) {

        if (numbers[i] <= 0) {

            return false; // ברגע שמצאנו מספר אחד שאינו חיובי - אפשר לעצור ולהחזיר false

        }

    }

    return true; // אם הלולאה קיימה את כל הריצות ולא עצרה ב-false, סימן שכולם חיוביים

}

8. מחלקות ואובייקטים (Classes & Objects) – דגש מוגבר

תכנות מונחה עצמים (OOP).

  • מחלקה (Class): תבנית/תוכנית בניין (למשל, תבנית ליצירת "שעון", "תלמיד" או "רכב").
  • תכונות (Attributes / Fields): המשתנים של המחלקה (מוגדרים כ-private לשמירה על אנקפסולציה).
  • פעולה בונה (Constructor): פעולה מיוחדת ליצירת האובייקט (ללא ערך מוחזר, שם הפעולה כשם המחלקה).
  • Getter / Setter: פעולות המאפשרות גישה ועדכון של התכונות הפרטיות מחוץ למחלקה.

דוגמה מלאה ומורכבת (בניית מחלקה ושימוש בה):

שלב א': הגדרת המחלקה Student

Java

public class Student {

    // 1. תכונות (פרטיות)

    private String name;

    private int grade;

    // 2. פעולה בונה (Constructor)

    public Student(String name, int grade) {

        this.name = name;

        this.grade = grade;

    }

    // 3. פעולות גישה ועדכון (Getters & Setters)

    public String getName() {

        return this.name;

    }

    public int getGrade() {

        return this.grade;

    }

    public void setGrade(int grade) {

        if (grade >= 0 && grade <= 100) { // הגנה על הנתונים

            this.grade = grade;

        }

    }

   

    // 4. פעולה רגילה של האובייקט

    public boolean isExcellent() {

        return this.grade >= 90;

    }

}

שלב ב': שימוש במחלקה (בתוך ה-main של תוכנית אחרת)

כאן נראה יצירת אובייקטים, מערך של אובייקטים ומציאת מצטיינים – שילוב מעולה ומבוקש בבגרות:

Java

public class Main {

    public static void main(String[] args) {

        // יצירת עצמים (אובייקטים) בודדים

        Student s1 = new Student("Dana", 95);

        Student s2 = new Student("Yossi", 82);

        // שינוי ציון באמצעות Setter ושימוש ב-Getter

        s2.setGrade(88);

        System.out.println(s1.getName() + " is excellent? " + s1.isExcellent()); // true

        // --- מורכב: מערך של אובייקטים ---

        Student[] classList = new Student[3];

        classList[0] = s1;

        classList[1] = s2;

        classList[2] = new Student("Ron", 91);

        // הדפסת שמות כל התלמידים המצטיינים בכיתה

        System.out.println("Excellent students in class:");

        for (int i = 0; i < classList.length; i++) {

            // גישה לאובייקט במערך והפעלת פעולה שלו

            if (classList[i].isExcellent()) {

                System.out.println(classList[i].getName());

            }

        }

    }

}

טיפים קטנים עבור התלמידים לבגרות:

  1. לשים לב ל-this במחלקות: להזכיר להם ש-this.name מתייחס לתכונה של האובייקט, בעוד שסתם name מתייחס לפרמטר שהתקבל.
  2. חריגה מגבולות מערך (ArrayIndexOutOfBoundsException): הדגש החשוב ביותר בלולאות שרצות על מערכים – לא להגיע ל-i <= arr.length אלא תמיד להישאר קטן ממש (i < arr.length).
  3. אתחול מונים וסוכמים: לזכור לאפס משתני ספירה (count = 0) ומשתני סכום (sum = 0) לפני הלולאה שמפעילה אותם.

המון הצלחה בהכנות ובבחינה עצמה! אם יש צורך בחידוד של קטע קוד מסוים או תרגיל ספציפי, אני כאן.
