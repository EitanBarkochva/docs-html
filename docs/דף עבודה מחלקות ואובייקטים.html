דף עבודה: בניית מחלקות ויצירת אובייקטים (עצמים) ב-Java

הסבר על הפקודה והמושג: בשלב הקודם למדנו שמחלקה (class) היא כמו תוכנית אדריכלית או תבנית. בשלב זה נלמד כיצד משתמשים בתבנית הזו כדי ליצור "אובייקטים" (עצמים) אמיתיים בתוך הזיכרון של המחשב, וכיצד ניתו לגשת לתכונות שלהם ולהפעיל את הפעולות שלהם.

וריאציות ושימוש: כדי ליצור אובייקט חדש, אנו משתמשים במילת המפתח new. לאחר יצירת האובייקט, אנו משתמשים באופרטור הנקודה (.) כדי להגיע לתכונות שלו (למשל myObject.attribute = value;) או כדי להפעיל את הפעולות שלו.

שלב 1: העתקת קוד וניתוח (צעד אחר צעד)

בדף עבודה זה אנו זקוקים לשני קבצים נפרדים (או שני חלקים באותו פרויקט): מחלקת הישות (התבנית) ומחלקת ההרצה (שמדפיסה ומפעילה את הקוד).

דוגמה א': מחלקת ישור ומחלקת הרצה עבור "חתול"

  1. פתחו קובץ בשם Cat.java והעתיקו אליו רק את התוכן שבתוך הקווים המקווקווים:

Java

public class Cat {

    // תכונות החתול

    public String name;

    public int age;

    // פעולה של החתול

    public void meow() {

        System.out.println(name + " אומר: מיאו!");

    }

}

  1. פתחו קובץ נוסף באותו פרויקט בשם MainApp.java והעתיקו אליו רק את התוכן הבא:

Java

public class MainApp {

    public static void main(String[] args) {

        // 1. יצירת האובייקט (החתול הראשון)

        Cat myCat = new Cat();

        // 2. השמת ערכים לתכונות שלו

        myCat.name = "מיצי";

        myCat.age = 3;

        // 3. הפעלת הפעולה שלו

        myCat.meow();

    }

}

שאלה למחשבה: הביטו בקוד של MainApp.java. מה תפקידה של השורה Cat myCat = new Cat(); וכיצד השתמשנו בשם החתול בתוך הפעולה meow?

שלב 2: מעקב אחר קוד וחיזוי פレット

לפניכם קוד מלא המגדיר מחלקה ומפעיל שני אובייקטים שונים מתוכה. קראו את הקוד בעיון וכתבו מה יהיה הפלט המדויק שיודפס למסך.

תרגיל מעקב 1:

Java

class Dog {

    public String breed;

    public boolean isTrained;

    public void bark() {

        if (isTrained) {

            System.out.println(breed + " barks politely!");

        } else {

            System.out.println(breed + " barks loudly!");

        }

    }

}

public class DogTest {

    public static void main(String[] args) {

        Dog dog1 = new Dog();

        dog1.breed = "Labrador";

        dog1.isTrained = true;

        Dog dog2 = new Dog();

        dog2.breed = "Chihuahua";

        dog2.isTrained = false;

        dog1.bark();

        dog2.bark();

    }

}

שלב 4: תרגול מעשי עצמאי (מדורג מהקל אל הקשה)

בכל אחד מהתרגילים הבאים יש לכתוב את מחלקת הישות, וכן מחלקת הרצה (Main) שבה תצרו את האובייקטים ותבדקו אותם.

תרגיל 1 (קל מאוד)

צרו מחלקה בשם Person עם התכונות: שם וגיל. במחלקת ההרצה צרו אובייקט אחד שמייצג אתכם (השם והגיל שלכם) והדפיסו את התכונות שלו למסך.

תרגיל 2 (קל)

צרו מחלקה בשם Lamp (מנורה) עם תכונה בוליאנית בשם isLit (האם דולקת). הוסיפו לה פעולה בשם printStatus שמדפיסה "The lamp is on" או "The lamp is off" בהתאם למצב. במחלקת ההרצה צרו מנורה, כבו אותה, והפעילו את הפעולה.

תרגיל 3 (קל)

צרו מחלקה בשם Team (קבוצת ספורט) עם תכונות: שם הקבוצה, ומספר הניצחונות שלה. הוסיפו פעולה בשם winMatch שמגדילה את מספר הניצחונות ב-1. במחלקת ההרצה צרו קבוצה, הגדירו לה 5 ניצחונות, הפעילו את הפעולה winMatch והדפיסו את המצב החדש.

תרגיל 4 (בינוני)

צרו מחלקה בשם Wallet (ארנק) עם תכונה של כמות כסף בשקלים (מספר שלם). הוסיפו פעולה בשם canBuy המקבלת כפרמטר מחיר של מוצר (מספר שלם) ומחזירה true אם יש מספיק כסף בארנק, ואחרת מחזירה false. במחלקת ההרצה: צרו ארנק עם 50 שקלים, ובדקו בעזרת הפעולה האם ניתן לקנות מוצר שעולה 60 שקלים.

תרגיל 5 (בינוני)

צרו מחלקה בשם TV (טלוויזיה) עם התכונות: channel (מספר שלם) ו-volume (מספר שלם). הוסיפו פעולה בשם setChannel המקבלת מספר ערוץ ומעדכנת אותו רק אם המספר הוא בין 1 ל-99. במחלקת ההרצה צרו טלוויזיה ונסו להעביר אותה לערוץ 150 (ודאו שהערוץ לא משתנה).

תרגיל 6 (בינוני)

בנו מחלקה בשם User המייצגת משתמש באתר אינטרנט. תכונות: שם משתמש (username) וסיסמה (password). הוסיפו פעולה בשם login המקבלת כפרמטרים מחרוזת של שם ומחרוזת של סיסמה, ומחזירה true רק אם שני הפרמטרים תואמים בדיוק לתכונות המשתמש באובייקט.

תרגיל 7 (מתקדם)

צרו מחלקה בשם Elevator (מעלית). תכונות: currentFloor (הקומה הנוכחית, מתחילה ב-0) ו-maxFloor (הקומה הגבוהה ביותר בבניין). הוסיפו פעולה בשם goUp שמקדמת את המעלית בקומה אחת למעלה, אך ורק אם היא עדיין לא הגיעה לקומה המקסימלית.

תרגיל 8 (מתקדם)

צרו מחלקה בשם StepCounter (מד צעדים). תכונות: מספר הצעדים שבוצעו היום. הוסיפו פעולות:

  1. addSteps(int amount) - מוסיפה את כמות הצעדים שנמסרה.
  2. getCaloriesBurned() - מחזירה את כמות הקלוריות שנשרפו (נניח שכל 20 צעדים שורפים קלוריה אחת, כלומר מספר הצעדים חלקי 20). במחלקת ההרצה צרו אובייקט, הוסיפו לו 4,000 צעדים והדפיסו כמה קלוריות נשרפו.

תרגיל 9 (קשה)

צרו מחלקה בשם FuelTank (מיכל דלק של מכונית). תכונות: קיבולת מקסימלית (למשל 50 ליטר) וכמות הדלק הנוכחית בליטרים. הוסיפו פעולה בשם refuel המקבלת כפרמטר כמות ליטרים למילוי. הפעולה תמלא את המיכל, אך אם הכמות חורגת מהקיבולת המקסימלית - המיכל יתמלא רק עד המקסימום והשאר "ישפך" (כלומר, הכמות הנוכחית פשוט תהפוך שווה למקסימום).

תרגיל 10 (אתגר)

צרו מחלקה בשם Match (משחק כדורגל קבוצתי). תכונות: שם קבוצת הבית, שם קבוצת החוץ, שערים לבית, שערים לחוץ. הוסיפו פעולות: goalHome() ו-goalAway() המעלות את התוצאה של הקבוצה המתאימה ב-1. הוסיפו פעולה בשם getWinnerName() המחזירה את שם הקבוצה המנצחת (זו שהבקיעה יותר שערים). אם יש תיקו, הפעולה תחזיר את המחרוזת "Tie". במחלקת ההרצה: צרו משחק בין "Maccabi" ל-"Hapoel", הבקיעו 2 שערים לטובת מכבי ושער 1 לטובת הפועל, והדפיסו את שם המנצחת באמצעות הפעולה.
