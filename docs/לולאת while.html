דף עבודה: לולאת while בשפת Java

הסבר על הפקודה:

לולאת while היא מבנה בקרה המאפשר לחזור על קטע קוד שוב ושוב כל עוד תנאי מסוים מתקיים (True). ברגע שהתנאי הופך לשקרי (False), התוכנית מפסיקה את הלולאה וממשיכה לשורה הבאה אחריה.

וריאציות ודגשים:

חשוב מאוד לעדכן את המשתנה שמשתתף בתנאי בתוך גוף הלולאה (למשל קידום מונה), אחרת ניקלע ל"לולאה אינסופית" שתגרום לתוכנית "להיתקע".

שלב 1: העתקת קוד (דוגמאות)

העתיקו את תוכן הקוד הבא לתוך פרויקט חדש ב-Eclipse או IntelliJ. שימו לב לשם המחלקה.

דוגמה א': הדפסת מספרים מ-1 עד 5 שם המחלקה: NumberPrinter

Java

int i = 1;

while (i <= 5) {

    System.out.println("המספר הוא: " + i);

    i++; // קידום המונה ב-1

}

דוגמה ב': צבירת סכום מספרים עד שמתקבל 0 שם המחלקה: SumCollector

Java

Scanner reader = new Scanner(System. serums);

int sum = 0;

System.out.println("הכנס מספר (0 ליציאה):");

int num = reader.nextInt();

while (num != 0) {

    sum += num;

    System.out.println("הכנס מספר נוסף:");

    num = reader.nextInt();

}

System.out.println("הסכום הכולל הוא: " + sum);

שלב 4: משימות תכנות (מהקל אל הכבד)

כתבו תוכנית מלאה עבור כל אחד מהתרגילים הבאים:

  1. ספירה לאחור: קלטו מספר מהמשתמש והדפיסו את כל המספרים ממנו ועד 1 בסדר יורד.
  2. מכפלות של 5: הדפיסו את כל הכפולות של 5 מ-5 ועד 50.
  3. בדיקת סיסמה: קלטו מהמשתמש מספר (סיסמה). המשיכו לקלוט שוב ושוב כל עוד המספר אינו 1234. כשהוא צודק, הדפיסו "ברוך הבא".
  4. ממוצע ציונים: קלטו ציונים מהמשתמש עד שיוקש המספר 1-. בסיום הציגו את ממוצע הציונים (רמז: השתמשו במונה ובמשתנה סכום).
  5. ערך מקסימלי: קלטו סדרת מספרים חיוביים (עד שנקלט 0). הדפיסו מה היה המספר הגבוה ביותר שנקלט.
  6. עצרת: קלטו מספר $n$ וחשבו את העצרת שלו ($1 \cdot 2 \cdot 3 \dots \cdot n$).
  7. כמות ספרות: קלטו מספר שלם חיובי. בעזרת לולאת while וחילוק ב-10, מצאו כמה ספרות יש במספר.
  8. סדרת פיבונאצ'י: הדפיסו את איברי סדרת פיבונאצ'י שערכם קטן מ-100.
  9. ניחוש מספר: הגרלו מספר בין 1 ל-100. תנו למשתמש לנחש עד שיצליח, ובכל פעם רשמו לו אם המספר "גבוה מדי" או "נמוך מדי".
  10. ריבוע מספרים: קלטו מספר $N$. הדפיסו את כל הריבועים של המספרים (כלומר $i^2$) שהתוצאה שלהם קטנה מ-$N$.

בהצלחה! לולאת while היא כלי חזק מאוד, תרגלו אותה היטב.
