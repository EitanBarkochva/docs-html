תקציר ג'אווה לבגרות צ'ט – 3 יח"ל

1. הדפסה למסך

הפקודה הבסיסית:

System.out.println("שלום");

מדפיסה שורה ויורדת שורה.

אם רוצים בלי ירידת שורה:

System.out.print("שלום");

דוגמאות:

System.out.println("Hello World");

System.out.println(5);

System.out.println(5+3);

פלט:

Hello World

5

8

שילוב משתנים:

String name = "Eitan";

System.out.println("Hello " + name);

2. משתנים

משתנה = מקום בזיכרון ששומר מידע.

סוגים:

int age = 25;         // מספר שלם

double price = 19.5;  // עשרוני

char letter = 'A';    // תו

boolean flag = true;  // אמת/שקר

String name = "David";// טקסט

פעולות:

int x = 5;

int y = 2;

System.out.println(x+y); // 7

System.out.println(x-y); // 3

System.out.println(x*y); // 10

System.out.println(x/y); // 2

System.out.println(x%y); // 1

קיצור:

x++;

x--;

x+=5;

x*=2;

int num = input.nextInt();

double x = input.nextDouble();

System.out.println("Enter age:");

int age = input.nextInt();

System.out.println("Your age is " + age);

5. לולאות While

רץ כל עוד התנאי מתקיים.

int i = 1;

while(i <= 5)

{

    System.out.println(i);

    i++;

}

פלט:

1 2 3 4 5

דוגמה מורכבת:

סכום עד שהמשתמש מכניס 0

int num;

int sum = 0;

num = input.nextInt();

while(num != 0)

{

    sum += num;

    num = input.nextInt();

}

System.out.println(sum);

6. לולאת For

כשיודעים מראש כמה פעמים.

for(int i=1; i<=10; i++)

{

    System.out.println(i);

}

מבנה:

for(התחלה; תנאי; שינוי)

דוגמה מורכבת:

טבלת כפל:

for(int i=1;i<=10;i++)

{

    for(int j=1;j<=10;j++)

    {

        System.out.print(i*j + " ");

    }

    System.out.println();

}

7. מערכים

מערך = אוסף משתנים מאותו סוג.

יצירה:

int[] arr = new int[5];

הכנסה:

arr[0] = 10;

arr[1] = 20;

שליפה:

System.out.println(arr[0]);

מעבר על מערך:

for(int i=0;i<arr.length;i++)

{

    System.out.println(arr[i]);

}

קליטה למערך:

for(int i=0;i<arr.length;i++)

{

    arr[i] = input.nextInt();

}

דוגמאות חשובות:

מציאת מקסימום:

int max = arr[0];

for(int i=1;i<arr.length;i++)

{

    if(arr[i] > max)

        max = arr[i];

}

ממוצע:

int sum = 0;

for(int i=0;i<arr.length;i++)

{

    sum += arr[i];

}

double avg = (double)sum / arr.length;

8. פונקציות (חשוב מאוד)

פונקציה = קטע קוד שמבצע פעולה.

מבנה:

public static סוג שם()

{

}

ללא החזרה:

public static void hello()

{

    System.out.println("Hello");

}

קריאה:

hello();

עם החזרה:

public static int sum(int a,int b)

{

    return a+b;

}

קריאה:

int x = sum(5,3);

דוגמה מורכבת:

בדיקת מספר ראשוני:

public static boolean isPrime(int num)

{

    for(int i=2;i<num;i++)

    {

        if(num%i==0)

            return false;

    }

    return true;

}

שימוש:

if(isPrime(7))

    System.out.println("Prime");

9. מחלקות ואובייקטים (חשוב מאוד)

מחלקה = תבנית.

public class Student

{

    String name;

    int grade;

}

אובייקט:

Student s1 = new Student();

הכנסת ערכים:

s1.name = "Eitan";

s1.grade = 95;

הדפסה:

System.out.println(s1.name);

Constructor (בנאי)

פועל בזמן יצירת האובייקט:

public class Student

{

    String name;

    int grade;

    public Student(String n,int g)

    {

        name = n;

        grade = g;

    }

}

יצירה:

Student s1 = new Student("David",90);

פעולה בתוך מחלקה

public void show()

{

    System.out.println(name + " " + grade);

}

קריאה:

s1.show();

דוגמה גדולה שמשלבת הכול:

import java.util.Scanner;

public class Main

{

    public static int sumArray(int[] arr)

    {

        int sum=0;

        for(int i=0;i<arr.length;i++)

        {

            sum+=arr[i];

        }

        return sum;

    }

    public static void main(String[] args)

    {

        Scanner input = new Scanner(System.in);

        int[] arr = new int[5];

        for(int i=0;i<arr.length;i++)

        {

            arr[i] = input.nextInt();

        }

        int total = sumArray(arr);

        if(total > 50)

            System.out.println("Big");

        else

            System.out.println("Small");

    }

}

מה חשוב לבגרות?

שים דגש חזק על:
✅ לולאות בתוך לולאות
✅ מערכים + פונקציות
✅ שליחת מערך לפונקציה
✅ החזרת ערך מפונקציה
✅ חיפוש מקסימום/מינימום
✅ ספירה (כמה זוגיים וכו')
✅ מחלקות + בנאי + פעולות
✅ יצירת כמה אובייקטים במערך
