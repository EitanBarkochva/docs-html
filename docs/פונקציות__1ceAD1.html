דף עבודה: פונקציות (שיטות) ב-Java - שלב אחר שלב

הגדרה: פונקציה היא קטע קוד עצמאי שמקבל "קלט" (פרמטרים), מבצע פעולה ומחזיר "פלט" (ערך חזור).

וריאציות: קיימות פונקציות שמבצעות פעולה בלי להחזיר ערך (מסוג void) וכאלו שמחזירות ערך (כמו int, double או boolean).

שלב 1: העתקה והרצה

העתיקו את תוכן הקוד הבא. שימו לב לשם המחלקה התואם לנושא.

דוגמה 1: פונקציה לחישוב סכום (החזרת ערך)

Java

public class CalculatorPro {

    public static void main(String[] args) {

        int a = 5;

        int b = 10;

        // קריאה לפונקציה ושמירת התוצאה במשתנה

        int total = addNumbers(a, b);

        System.out.println("הסכום הוא: " + total);

    }

    // --------------------------------------------------

    // העתק מכאן:

    public static int addNumbers(int num1, int num2) {

        int sum = num1 + num2;

        return sum;

    }

    // עד כאן.

    // --------------------------------------------------

}

דוגמה 2: פונקציה עם קלט מהמשתמש ותנאי (ללא החזרת ערך)

Java

import java.util.Scanner;

public class AgeChecker {

    public static void main(String[] args) {

        checkEntrance(); // קריאה לפונקציה

    }

    // --------------------------------------------------

    // העתק מכאן:

    public static void checkEntrance() {

        Scanner reader = new Scanner(System.in);

        System.out.println("נא להקיש גיל:");

        int age = reader.nextInt();

        if (age >= 16) {

            System.out.println("ברוכים הבאים לסרט!");

        } else {

            System.out.println("מצטערים, הסרט למבוגרים בלבד.");

        }

    }

    // עד כאן.

    // --------------------------------------------------

}

שלב 4: משימות תכנות (מהקל אל הכבד)

  1. הדפסת ריבוע: כתוב פונקציה המקבלת מספר שלם ומדפיסה את הריבוע שלו (המספר כפול עצמו).
  2. חיבור שלשות: כתוב פונקציה המקבלת 3 מספרים שלמים ומחזירה את סכומם.
  3. בודק זוגיות: כתוב פונקציה המקבלת מספר ומדפיסה "Even" אם הוא זוגי ו-"Odd" אם הוא אי-זוגי. (רמז: % 2 == 0).
  4. המרה לסנטימטרים: כתוב פונקציה המקבלת אורך במטרים ומחזירה את האורך בס"מ.
  5. גדול מבין שלושה: כתוב פונקציה המקבלת 3 מספרים ומחזירה את הגדול מביניהם (השתמש ב-if-else).
  6. ממוצע ציונים: כתוב פונקציה שקולטת מהמשתמש 2 ציונים ומדפיסה את הממוצע שלהם.
  7. חישוב שכר: כתוב פונקציה המקבלת מספר שעות עבודה ותעריף לשעה, ומחזירה את השכר הכולל.
  8. בדיקת ציון עובר: כתוב פונקציה המקבלת ציון. אם הציון 55 ומעלה החזר true, אחרת החזר false.
  9. הנחה מותנית: כתוב פונקציה המקבלת מחיר קנייה. אם המחיר מעל 500 ש"ח, החזר מחיר עם 50 ש"ח הנחה. אחרת, החזר את המחיר המקורי.
  10. מחשבון תווים: כתוב פונקציה המקבלת שני מספרים ותו (+ או -). אם התו הוא + החזר את הסכום, אם - החזר את ההפרש.
