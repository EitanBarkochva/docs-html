פונקציות (שיטות - Methods).

פונקציה היא "מכונה" של קוד שמבצעת משימה ספציפית. היא מאפשרת לנו לא לכתוב את אותו הקוד פעמיים, לשמור על סדר בתוכנית ולחלק בעיה גדולה לתתי-משימות קטנות ונוחות.

דף עבודה: הכרת הפונקציות (Methods) ב-Java

מה נלמד? כיצד להגדיר פונקציה שמקבלת ערכים, מבצעת חישובים (עם משתנים ותנאים) ומחזירה תוצאה או מדפיסה אותה.

שלב 1: העתקה והרצה

העתיקו את תוכן הקוד הבא לתוך סביבת העבודה שלכם (Eclipse/IntelliJ). שימו לב לשם המחלקה.

דוגמה 1: פונקציה ללא החזרת ערך (void)

Java

public class FunctionLearning {

    public static void main(String[] args) {

        // קריאה לפונקציה

        printHello("יוסי");

    }

    // --------------------------------------------------

    // העתק מכאן:

    public static void printHello(String name) {

        System.out.println("שלום " + name + ", ברוך הבא לעולם הפונקציות!");

    }

    // עד כאן.

    // --------------------------------------------------

}

דוגמה 2: פונקציה עם תנאי והחזרת ערך (return)

Java

public class CheckNumbers {

    public static void main(String[] args) {

        int result = getMax(10, 20);

        System.out.println("המספר הגדול הוא: " + result);

    }

    // --------------------------------------------------

    // העתק מכאן:

    public static int getMax(int num1, int num2) {

        if (num1 > num2) {

            return num1;

        } else {

            return num2;

        }

    }

    // עד כאן.

    // --------------------------------------------------

}

שאלה למחשבה: מה לדעתך התפקיד של המילה static ומה ההבדל בין פונקציה שכתוב בה void לפונקציה שכתוב בה int?

שלב 4: משימות תכנות (מקל לקשה)

  1. שלום אישי: כתוב פונקציה המקבלת שם ומדפיסה "בוקר טוב" בצירוף השם.
  2. חיבור מספרים: כתוב פונקציה המקבלת שני מספרים שלמים ומחזירה את סכומם.
  3. ממוצע: כתוב פונקציה המקבלת שלושה מספרים ומחזירה את הממוצע שלהם (double).
  4. חיובי/שלילי: כתוב פונקציה המקבלת מספר ומדפיסה "Positive" אם הוא גדול מ-0, ו-"Negative" אחרת.
  5. קלט וחישוב: כתוב פונקציה שקולטת מהמשתמש רדיוס של מעגל ומחזירה את היקפו (רמז: $2 \cdot \pi \cdot r$).
  6. בדיקת טווח: כתוב פונקציה המקבלת מספר ובודקת אם הוא בין 1 ל-100 (כולל). החזר true או false.
  7. הנחה במחיר: כתוב פונקציה המקבלת מחיר מוצר. אם המחיר מעל 200 ש"ח, היא מחזירה את המחיר לאחר 10% הנחה. אחרת, מחזירה את המחיר המקורי.
  8. סיסמה נכונה: כתוב פונקציה שקולטת מספר מהמשתמש בתוך לולאה עד שהוא מקיש את המספר 1234. (רמז: השתמש ב-while).
  9. דירוג ציונים: כתוב פונקציה המקבלת ציון (0-100) ומחזירה תו: 'A' ל-90 ומעלה, 'B' ל-80 ומעלה, 'C' לכל השאר.
  10. מחשבון פשוט: כתוב פונקציה המקבלת שני מספרים ותו (+, -, *, /). השתמש ב-switch או ב-if כדי לבצע את הפעולה המתמטית ולהחזיר את התוצאה.
