דף עבודה בנושא: מערכים חד-ממדיים בשפת Java

קהל יעד: כיתה י' (מדעי המחשב)

הסבר קצר על הפקודה הנלמדת:

מערך (Array) הוא מבנה נתונים המאפשר לנו לשמור מספר רב של משתנים מאותו הסוג תחת שם אחד וגישה אליהם באמצעות אינדקס (מיקום). נשתמש במערך כאשר נרצה לנהל רשימת נתונים (כמו ציוני כיתה או טמפרטורות) מבלי להגדיר משתנה נפרד לכל פריט.

וריאציות של הפקודה:

  1. הגדרה ויצירת מערך ריק בגודל קבוע מראש: int[] arr = new int[5]; (מייצר מערך של 5 תאים המאותחלים ל-0).
  2. הגדרה ואתחול מערך עם ערכים ידועים מראש: int[] arr = {10, 20, 30};.

שלב 1: העתקה והתנסות ראשונית

לפניכם שתי דוגמאות לקוד מוגמר. העתיקו לסביבת הפיתוח שלכם (כמו Eclipse / IntelliJ) רק את תוכן הקוד שנמצא בין הקווים המקווקווים. שימו לב לשם המחלקה הרלוונטי.

דוגמה א': יצירת מערך והדפסת איבר

Java

// --------------------------------------------------

public class ArrayBasics {

    public static void main(String[] args) {

        // יצירת מערך של מספרים שלמים בגודל 3

        int[] grades = new int[3];

       

        // הכנסת ערכים לתוך המערך לפי אינדקס (מתחילים מ-0!)

        grades[0] = 95;

        grades[1] = 88;

        grades[2] = 100;

       

        // הדפסת האיבר השני במערך

        System.out.println("The grade at index 1 is: " + grades[1]);

    }

}

// --------------------------------------------------

דוגמה ב': אתחול מהיר ומעבר על מערך עם לולאה

Java

// --------------------------------------------------

public class ArrayLoop {

    public static void main(String[] args) {

        // אתחול מהיר של מערך עם ערכים

        int[] MyNumbers = {5, 10, 15, 20};

       

        // הדפסת אורך המערך בעזרת תכונת ה-length

        System.out.println("Array length: " + MyNumbers.length);

       

        // לולאה שעוברת על כל איברי המערך ומדפיסה אותם

        for (int i = 0; i < MyNumbers.length; i++) {

            System.out.println("Element at index " + i + " is: " + MyNumbers[i]);

        }

    }

}

// --------------------------------------------------

שלב 4: משימות תכנות עצמאיות (מדורג מהקל אל הקשה)

כתבו תוכנית מלאה ב-Java עבור כל אחד מהסעיפים הבאים.

תרגיל 1 (קל מאוד):

צרו מערך של מספרים שלמים בגודל 4. קלטו מהמשתמש 4 מספרים לתוכו והדפיסו את האיבר שנמצא במקום הראשון (אינדקס 0).

  • רמז: השתמשו ב-Scanner לקליטת הנתונים.

תרגיל 2 (קל):

צרו מערך מאותחל עם 5 שמות של חברים (טיפוס String). הדפסו את השם האמצעי במערך (אינדקס 2).

תרגיל 3 (קל):

כתבו תוכנית שמגדירה מערך של 6 מספרים שלמים ומחשבת את הממוצע של כל האיברים במערך.

  • רמז: סכמו את כל האיברים בעזרת לולאה, ובסוף חלקו באורך המערך (length). שימו לב להמרה ל-double לקבלת דיוק שברי.

תרגיל 4 (בינוני):

כתבו תוכנית שקולטת 7 מספרים שלמים לתוך מערך. התוכנית תדפיס כמה מהמספרים שנקלטו גדולים מהמספר 50.

תרגיל 5 (בינוני):

נתון מערך של מספרים שלמים. כתבו קוד שבודק האם המספר 10 קיים במערך. אם כן, הדפיסו "Found", אחרת הדפיסו "Not Found".

  • רמז: השתמשו במשתנה בוליאני (boolean flag = false;) שישתנה ל-true ברגע שהמספר נמצא.

תרגיל 6 (בינוני):

כתבו תוכנית המוצאת ומדפיסה את הערך המקסימלי (הכי גדול) במערך של מספרים שלמים.

  • רמז: הגדירו משתנה int max = arr[0]; ועדכנו אותו בתוך לולאה בכל פעם שאתם פוגשים איבר גדול ממנו.

תרגיל 7 (מתקדם):

כתבו תוכנית המקבלת מערך של מספרים שלמים ומייצרת מערך חדש באותו הגודל, שבו כל איבר הוא העתק של האיבר המקביל במערך המקורי, אך מוכפל ב-2.

תרגיל 8 (מתקדם):

כתבו תוכנית הבודקת האם מערך של מספרים שלמים הוא ממוין בסדר עולה (כלומר, כל איבר גדול או שווה לאיבר שלפניו). הדפיסו הודעה מתאימה.

  • רמז: רוצו עם לולאה עד length - 1 ובדקו בכל שלב האם arr[i] > arr[i+1]. אם התנאי מתקיים אפילו פעם אחת – המערך אינו ממוין.

תרגיל 9 (קשה):

היפוך מערך: נתון מערך כלשהו. כתבו קוד שהופך את סדר האיברים במערך עצמו (האיבר הראשון הופך לאחרון, השני לפני האחרון וכו'), מבלי ליצור מערך חדש!

  • רמז: השתמשו בלולאה שרצה רק עד חצי מאורך המערך, ובצעו החלפה (Swap) בין האיבר במקום ה-i לאיבר במקום ה-length - 1 - i.

תרגיל 10 (אתגר - קשה ביותר):

רצף ארוך ביותר: נתון מערך של מספרים שלמים הכולל רק את הספרות 0 ו-1. כתבו תוכנית שמוצאת ומדפיסה מהו אורך הרצף הארוך ביותר של המספר 1 שמופיע במערך ברצף (לדוגמה עבור {1, 0, 1, 1, 1, 0, 1} התשובה היא 3).

  • רמז: השתמשו בשני מונים: מונה אחד לרצף הנוכחי (currentStreak) שמתאפס בכל פעם שפוגשים 0, ומונה שני השומר את הרצף המקסימלי שנתגלה עד כה (maxStreak).
