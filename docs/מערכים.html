דף עבודה: מבוא למערכים ב-Java

מהו מערך? מערך הוא מבנה נתונים המאפשר לשמור מספר רב של ערכים מאותו סוג (למשל, הרבה מספרים שלמים) תחת שם משתנה אחד, במקום להגדיר משתנה נפרד לכל ערך.

גישה לנתונים: הגישה לכל איבר במערך מתבצעת באמצעות "אינדקס" (מיקום), כאשר הספירה תמיד מתחילה מ-0.

שלב 1: התנסות ראשונית – העתקת קוד

העתיקו את תוכן הקוד הבא לסביבת העבודה שלכם (Eclipse/IntelliJ). שימו לב לשם המחלקה.

דוגמה ב': שינוי ערך במערך

Java

public class ArrayUpdate {

    public static void main(String[] args) {

        // ------------------------------------------

        int[] numbers = new int[3]; // מערך ריק בגודל 3

        numbers[0] = 10;

        numbers[1] = 20;

        numbers[2] = 30;

        numbers[1] = 50; // שינוי הערך במיקום 1

        System.out.println("Value at index 1 is: " + numbers[1]);

        // ------------------------------------------

    }

}

שלב 4: משימות תכנות (מהקל אל הקשה)

כתבו תוכנית שלמה לכל סעיף.

  1. הצהרה והדפסה: צרו מערך של 5 מספרים שלמים עם ערכים לבחירתכם. הדפיסו את האיבר הראשון והאחרון.
  2. סכום פשוט: צרו מערך של 3 מספרים שלמים. חשבו והדפיסו את סכומם (ללא לולאה).
  3. קלט מהמשתמש: צרו מערך בגודל 4. קלטו מהמשתמש מספר שלם והכניסו אותו לתא השני (אינדקס 1). הדפיסו את המערך.
  4. ממוצע ציונים: צרו מערך עם 3 ציונים. חשבו את הממוצע שלהם והדפיסו אותו. רמז: השתמשו ב-double.
  5. החלפת ערכים: צרו מערך עם 2 מספרים. החליפו בין הערכים שלהם (מה שבתא 0 יעבור לתא 1 ולהיפך). רמז: היעזרו במשתנה עזר temp.
  6. שימוש בלולאה להדפסה: צרו מערך בגודל 10 ומלאו אותו במספרים 1-10. השתמשו בלולאת for כדי להדפיס את כל איברי המערך.
  7. חיפוש ערך: צרו מערך של מספרים. כתבו קוד שבודק אם המספר 5 קיים בתא הראשון או האחרון ומדפיס "Found" אם כן.
  8. שינוי כל המערך: צרו מערך של 5 מספרים. בעזרת לולאה, הוסיפו 1 לכל איבר במערך.
  9. מציאת המקסימום: צרו מערך של 5 מספרים. בעזרת לולאה, מצאו והדפיסו את המספר הגבוה ביותר במערך. רמז: הגדירו משתנה max שמתחיל בערך של התא הראשון.
  10. היפוך מערך: צרו מערך בגודל 5. כתבו תוכנית שמעתיקה את איבריו למערך חדש אבל בסדר הפוך. רמז: היעזרו בלולאה שרצה מהסוף להתחלה.
